# Recursos y decisiones — EspaiFP

## Herramientas previstas

- **Hardware:** ordenador personal y conexión a Internet.
- **Sistema operativo:** Windows.
- **Editor:** Visual Studio Code.
- **Entorno local:** XAMPP con Apache y PHP.
- **Persistencia:** MariaDB y phpMyAdmin.
- **Control de versiones:** Git y GitHub.
- **Diagramas:** diagrams.net.
- **Pruebas:** navegadores actuales.
- **Documentación:** LibreOffice.

## Stack preliminar

HTML5, CSS3 y JavaScript en el frontend; PHP en el backend; MariaDB para persistencia; comunicación entre navegador y servidor mediante HTTP/HTTPS y JSON.

La decisión es preliminar y podrá ajustarse si las pruebas o las necesidades del proyecto lo justifican.

## Costes

El desarrollo inicial se realizará con recursos disponibles y herramientas con opciones gratuitas. La contratación de alojamiento y dominio se pospondrá hasta la fase de despliegue. Los importes deberán verificarse de nuevo antes de contratar cualquier servicio.

## Datos y autorizaciones

Se utilizarán datos ficticios durante el desarrollo académico. No se incluirán credenciales, tokens ni datos personales reales en el repositorio.
