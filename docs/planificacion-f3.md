# Planificación de ejecución — EspaiFP

## Datos generales

- Proyecto: EspaiFP.
- Módulo: 2CFSS · Projecte intermodular 2.
- Ciclo: Desarrollo de Aplicaciones Web.
- Curso: 2026-2027.
- Responsable: Juan Antonio Torregrosa Macia.

## Objetivo

Organizar las tareas necesarias para desarrollar EspaiFP, estableciendo su orden, dependencias, recursos y tiempos previstos.

## Organización del desarrollo

El proyecto se divide en las siguientes etapas:

1. Análisis de requisitos.
2. Preparación del entorno y repositorio.
3. Diseño de la base de datos y de la interfaz.
4. Estructuración del proyecto.
5. Desarrollo de autenticación y permisos.
6. Gestión de aulas y disponibilidad.
7. Gestión de reservas y control de solapamientos.
8. Desarrollo e integración del frontend.
9. Validación y pruebas.
10. Despliegue.
11. Documentación y entrega.

## Planificación temporal

El periodo previsto de ejecución es del 16 de noviembre de 2026 al 9 de mayo de 2027, con una estimación inicial de 116 horas de trabajo.

Esta planificación podrá modificarse en función de la evolución del proyecto y de la carga de trabajo de los demás módulos.

## Recursos

- Ordenador personal.
- Windows 11.
- Visual Studio Code.
- XAMPP.
- PHP y MariaDB.
- Git y GitHub.
- diagrams.net.
- Navegadores web.
- LibreOffice.

## Procedimiento de trabajo

Se utilizará Git para registrar los cambios del código y GitHub para mantener el repositorio remoto.

Las tareas se organizarán mediante identificadores y estados. Se realizarán commits cuando se completen avances significativos y se documentarán los problemas e incidencias.

## Responsabilidad

El proyecto será desarrollado individualmente por el alumno, que asumirá las funciones de análisis, diseño, desarrollo frontend y backend, gestión de datos, pruebas y documentación.
