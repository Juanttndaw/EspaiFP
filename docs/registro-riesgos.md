# Registro inicial de riesgos — EspaiFP

| Riesgo | Probabilidad | Impacto | Prevención | Respuesta si ocurre |
|---|---|---|---|---|
| Retrasos en tareas | Media | Medio | Revisión semanal y margen en el cronograma | Reordenar tareas y priorizar funciones esenciales |
| Dificultades con PHP o MariaDB | Media | Alto | Consultar documentación y hacer pruebas pequeñas | Aislar el error y ajustar la solución o planificación |
| Problemas de integración | Media | Alto | Probar periódicamente peticiones HTTP y respuestas JSON | Revisar contratos, datos y errores del servidor |
| Reservas solapadas | Media | Alto | Validación en servidor y comprobación de disponibilidad | Corregir la lógica y repetir pruebas de concurrencia |
| Pérdida de código o archivos | Baja | Alto | Git, GitHub y copias locales | Recuperar la última versión y rehacer cambios pendientes |
| Fallo de despliegue | Media | Medio | Comprobar compatibilidad del alojamiento | Revisar configuración o utilizar entorno alternativo |
| Acceso no autorizado | Baja | Alto | Hash de contraseñas, sesiones y control de permisos | Revocar acceso, revisar registros y corregir vulnerabilidad |
| Fatiga visual o molestias posturales | Media | Medio | Pausas, iluminación y ergonomía | Detener la actividad y corregir condiciones del puesto |

Las valoraciones son iniciales y se revisarán durante la ejecución.

## Prevención durante el trabajo informático

Mantener una postura cómoda, ajustar la altura de la pantalla y la silla, evitar reflejos, disponer de iluminación adecuada, realizar pausas periódicas y mantener cables y conexiones ordenados.
