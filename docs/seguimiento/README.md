# Documentación de seguimiento y control

Esta carpeta contiene los documentos y registros utilizados para realizar el seguimiento y control del proyecto EspaiFP.

Se conservarán los registros de tareas, indicadores de calidad, pruebas, incidencias, cambios, evaluación de usuarios y cumplimiento de requisitos.

La documentación se actualizará durante el desarrollo del proyecto para mantener un historial de su evolución.
