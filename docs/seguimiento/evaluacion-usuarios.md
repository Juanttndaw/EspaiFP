
# Evaluación de usuarios – EspaiFP

Este documento contiene el procedimiento y el cuestionario que se utilizarán para evaluar la facilidad de uso de EspaiFP.

El objetivo es comprobar si las personas que utilizarán la aplicación pueden localizar aulas, consultar su disponibilidad y realizar reservas de forma comprensible y sencilla.

## 1. Participantes

La evaluación estará dirigida principalmente a personas que representen los perfiles previstos para la aplicación:

- **Profesorado:** usuarios que necesitan consultar aulas disponibles, realizar reservas y consultar sus propias solicitudes.
- **Administración:** usuarios que necesitan gestionar las aulas y supervisar las reservas.

Se intentará contar con la participación de entre tres y cinco personas, como compañeros de clase, familiares u otras personas que puedan realizar las tareas propuestas.

No será necesario recoger nombres ni datos personales. Cada participante se identificará mediante un código.

## 2. Momento de realización

La evaluación se realizará cuando exista una versión funcional de EspaiFP que permita completar las principales operaciones de reserva.

En esta fase solamente se prepara el procedimiento y el cuestionario. La evaluación todavía no se ha realizado.

## 3. Tareas propuestas

Se pedirá a cada participante que realice las siguientes actividades:

1. Localizar un aula disponible para una fecha y un horario determinados.
2. Consultar las características y la disponibilidad del aula seleccionada.
3. Completar el formulario y realizar una reserva.
4. Consultar posteriormente la información de la reserva realizada.

Durante la actividad se observará si el usuario comprende las opciones disponibles, encuentra fácilmente los apartados y puede completar las operaciones sin ayuda.

## 4. Cuestionario de evaluación

Después de realizar las tareas, cada participante responderá a las siguientes preguntas:

| Nº | Pregunta | Respuesta |
|---|---|---|
| 1 | ¿Te ha resultado fácil encontrar un aula disponible? | 1 / 2 / 3 / 4 / 5 |
| 2 | ¿Has comprendido la información sobre la disponibilidad de las aulas? | 1 / 2 / 3 / 4 / 5 |
| 3 | ¿Te ha resultado sencillo completar el formulario de reserva? | 1 / 2 / 3 / 4 / 5 |
| 4 | ¿Has podido consultar correctamente la información de tu reserva? | 1 / 2 / 3 / 4 / 5 |
| 5 | ¿Los botones, etiquetas y mensajes son fáciles de entender? | 1 / 2 / 3 / 4 / 5 |
| 6 | ¿Te ha resultado sencilla la navegación general por la aplicación? | 1 / 2 / 3 / 4 / 5 |

**Escala de valoración:**

- 1: Muy difícil.
- 2: Difícil.
- 3: Normal.
- 4: Fácil.
- 5: Muy fácil.

## 5. Observaciones y propuestas de mejora

Además de las preguntas anteriores, se recogerán las siguientes observaciones:

- ¿Has encontrado alguna dificultad durante la utilización de la aplicación?
- ¿Ha habido algún mensaje o apartado que no hayas comprendido?
- ¿Qué cambiarías para mejorar la aplicación?
- ¿Qué funcionalidad te ha resultado más útil?

Las respuestas permitirán identificar posibles problemas de navegación, comprensión de los formularios y presentación de la información.

## 7. Análisis de los resultados

Cuando se realicen las evaluaciones, se revisarán las respuestas para identificar las dificultades que aparezcan con mayor frecuencia.

Las valoraciones permitirán conocer qué partes de la aplicación resultan más sencillas y cuáles necesitan mejoras.

Las propuestas se clasificarán según su importancia y su relación con los objetivos de EspaiFP. Cuando una observación implique modificar alguna funcionalidad o la planificación, se valorará mediante el procedimiento de gestión de cambios.

Los resultados y las conclusiones se conservarán en esta documentación para poder consultarlos durante las siguientes fases del proyecto.

La evaluación se considera pendiente hasta que exista una versión funcional y los participantes hayan realizado las tareas propuestas.
