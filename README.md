# EspaiFP

**Sistema de reserva y gestión de aulas para centros de Formación Profesional.**

## Descripción

EspaiFP es un proyecto de aplicación web cuyo objetivo es facilitar la gestión y reserva de aulas y espacios en centros educativos de Formación Profesional.

La aplicación permitirá centralizar las reservas, consultar la disponibilidad de los espacios y evitar conflictos de horarios.

## Problema que pretende resolver

La gestión de las solicitudes de utilización de aulas puede generar dificultades cuando la información se encuentra repartida entre diferentes canales de comunicación.

EspaiFP pretende mejorar este proceso mediante un sistema centralizado que facilite la consulta y administración de las reservas.

## Usuarios principales

- **Profesorado:** podrá consultar aulas disponibles, crear reservas, consultar sus solicitudes, modificarlas y cancelarlas.
- **Administrador:** podrá gestionar las aulas, los usuarios y las reservas, además de bloquear espacios temporalmente.

## Funcionalidades previstas

- Inicio de sesión y control de permisos.
- Consulta de aulas y disponibilidad.
- Creación, consulta, modificación y cancelación de reservas.
- Gestión de aulas y sus características.
- Prevención de reservas incompatibles o solapadas.
- Gestión administrativa de los espacios.

## Tecnologías previstas

- HTML5 y CSS3.
- JavaScript.
- PHP.
- MariaDB.
- Apache mediante XAMPP.
- Git y GitHub.

Estas tecnologías constituyen la propuesta inicial y podrán modificarse durante el desarrollo.
